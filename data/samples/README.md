# Telemetry Samples

This directory is reserved for small, safe-to-commit datasets used for demos, tests and schema examples.

Large FastF1/OpenF1 downloads belong under data/raw and are ignored by Git.

Recommended sample naming:

    <source>_<season>_<event>_<driver>_<session>.csv

The Streamlit dashboard also contains an offline synthetic telemetry generator, so a live API is not required for UI demonstrations.
